About

I build tools that try to run themselves. When they don't, I debug why.

I'm a 20-year-old computer science student at Culture & Science City in 6th of October City, Egypt.

I got into programming three years ago. I was translating English-Arabic legal documents on Khamsat to pay for a laptop, and I needed a faster way to rename files. My first script was 20 lines of Python that worked on the first try. I kept building after that.

Now I split my time between coursework and projects that try to write themselves. I take on Python and data engineering work on Mostaql when I need to cover server bills.

Right now I work on three things:

  • Gesture Control: hand-tracking desktop control with MediaPipe and OpenCV. My machine is an ASUS TUF A16 that I call Mira.
  • DevSquad Agent: a multi-agent system that reviews code across architecture, security, and design. It runs four specialized reviewers in parallel.
  • Fruit Slicer: a pygame arcade game I built to learn game loops and real-time input handling.

My path: CS50P, CS50 SQL, data engineering, AI/ML, autonomous agents. I want to get to the point where my systems pay for themselves before I graduate.

I've been diagnosed with ADHD and depression. I take medication for both. It means I work in intense bursts and then need to step away. The work comes out better for it, but the rhythm is uneven. This site shows what's shipped, not what's planned.
